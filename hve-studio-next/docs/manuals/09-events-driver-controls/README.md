# Events & Driver Controls

Dialog reference for setting up an **event** in HVE Studio: choosing the
calculation method and the humans and vehicles that take part, entering their
starting positions and velocities, the simulation controls, and the driver
inputs (steer, brake, throttle, gear and the HVE Driver path follower). Part of
the [HVE Manual](../README.md).

!!! note "HVE Studio"
    All of these are reached from the **Event** editor (F5). The **Event** menu
    and the **Event Information** panel replace HVE's Event Set-up menu and its
    Event Information dialog. Inputs for an event that has results on screen
    are read-only until the run is reset (press **Reset** under the viewport or
    in the Simulation panel); every one of these dialogs shows a banner saying
    so.
