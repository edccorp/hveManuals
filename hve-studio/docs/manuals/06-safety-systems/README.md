# Safety Systems

Dialog reference for the **Safety Systems** area: one page per HVE dialog, each describing the HVE Studio window that replaces it. Accelerometers, airbags and belt restraints are on the **Vehicle** menu of the Vehicle editor (F3) and the **Event** menu of the Event editor (F5); an airbag belongs to the vehicle, one per seat, in the **Airbags** window. Part of the [HVE Manual](../README.md).
