# HVE User's Manual — Section One: Overview

*The HVE Studio edition of the HVE User's Manual (HVE Version 5, Seventh Edition,
January 2006), "USING HVE" overview and Section One. The concepts — humans,
vehicles, environments, events and the physics programs — are HVE's and carry
over unchanged; how to use the program is rewritten for HVE Studio.*
