# HVE Studio

HVE Studio is the next version of HVE (Human Vehicle Environment): HVE's own
physics programs, compiled from HVE's own source code, in a new interface. It
opens HVE case files directly and runs on Windows and in a web browser.

This release is **HVE Studio**. "Preview" means HVE Studio does not yet do
everything the current release of HVE does. The word is dropped when it does;
until then, everything HVE does that HVE Studio does not is listed in
[Differences from HVE](05-differences-from-hve.md#not-available-in-hve-studio)
and marked on the page concerned.

This section is for a reader who knows HVE and wants to know what is the same,
what is different and how to get started. The rest of this manual set (the
dialog reference, the HVE User's Manual and the program manuals) describes the
physics and the inputs in HVE's terms, with every place HVE Studio differs marked
by an **HVE Studio**, **Not in HVE Studio** or **New in HVE Studio** box.

## Conventions used in this section

- Menu paths are written **Menu › Item**, exactly as they appear in the
  program.
- Keyboard keys are written as they are labelled: **F5**, **Ctrl+Z**, **G**.
- Lengths, speeds and forces are shown in the unit system chosen in
  **Tools › Preferences** (Imperial or Metric). Where this section quotes a
  field it does not hard-code a unit unless the dialog does.
