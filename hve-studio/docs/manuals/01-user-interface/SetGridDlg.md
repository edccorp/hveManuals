# Set Grid Dialog Box

HVE's Set Grid dialog sets a user-definable distance interval for display and data entry in the environment. Grid markers are used as spatial cues to help determine distances while creating and editing 3-D models of humans, vehicles and environments.

!!! warning "Not in HVE Studio"
    HVE Studio has no Set Grid dialog. The Viewport draws a datum grid when no site geometry is loaded (it is hidden once a site is loaded, so that it does not bury the terrain); it has no settings. Distances are entered numerically in the dialogs, and a vehicle can be moved by an exact amount in the Viewport by typing a number while moving it (for example **G**, then **X**, then a distance).
