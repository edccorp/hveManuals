# Human CG Dialog Box

In HVE, clicking the CG of a human segment displays a popup listing what can be
edited for that segment: Inertias, Color, Ellipsoids, Injury Tolerance and
Joints.

!!! warning "Not in HVE Studio"
    HVE Studio has no segment popup. In the Human editor (F2), clicking a body
    part in the 3-D view **selects that segment**, and the **Body Segments**
    window (opened with **Body Segments...** on the Occupants panel) follows the
    selection. The popup's items are found here instead:

    | HVE popup item | HVE Studio |
    |---|---|
    | Inertias... | Body Segments window, **Inertia** tab — [Inertial Data](Human.md) |
    | Color... | Body Segments window, **Segment Color** — [Inertial Data](Human.md) |
    | Ellipsoids... | Body Segments window, **Ellipsoids** tab — [Contact Ellipsoids](Human1.md) |
    | Injury Tolerance... | Occupants panel, **Injury Tolerances...** — [Injury Tolerance Data](Human2.md) |
    | Joints... | Body Segments window, **Joints** tab — [Joint Data](Human3.md) |

    The Occupants panel is opened with **Occupant › Human Information...**.

!!! tip "New in HVE Studio"
    The segment selected in the 3-D view is also the one the Shader Editor
    (View › Shader Editor) assigns a node material to.
