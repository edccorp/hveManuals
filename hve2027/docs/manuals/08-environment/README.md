# Environment

Dialog reference for the **Environment** area: one page per HVE dialog, each describing the HVE 2027 window that replaces it or saying where its function lives. The environment is edited in the Environment editor (F4) with **Environment › Environment...**, **Aerial Image...** and **Scene Box Editor...**; surface physics on the HVE Surface node in the Shader Editor. HVE's primitive editors (box, cone, cylinder, sphere) and surface editor have no HVE 2027 equivalent. This chapter also carries three dialogs reached from the vehicle: contact surfaces, their material, and brake lining friction. Part of the [HVE Manual](../README.md).
