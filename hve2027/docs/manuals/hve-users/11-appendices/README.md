## Notes on this edition

- The Tutorial follows HVE's four lessons with HVE 2027's menus and panels,
  using HVE's own tutorial cases, which HVE 2027 opens directly. Lesson 4
  (Creating a Video) sets up cameras and records the sequence with
  **File › Record Animation…**, or exports it to Blender; HVE's video-device
  steps have no counterpart. See also
  [Section Nine — Video Output](../09-video-output/README.md).
- Appendix I points to the HVE 2027 installation chapter; HVE's
  installation and licensing procedures do not apply, and HVE's file system
  tables are kept for reference with notes on which files HVE 2027 reads.
- Appendix II adds HVE 2027's run status and its `[defaulted: …]`
  disclosures, which replace HVE's message dialogs around the calculation
  models; the models' own messages are unchanged.
- Appendix III adds the coordinate frames of HVE 2027's dialogs and exports;
  Appendix IV describes HVE 2027's two unit systems (Tools › Preferences).
- Appendix IV's Environment Units table contained several descriptions
  mis-copied from the Engine table in the original printing; these have
  been corrected.
- Appendix IX adds a keyboard quick reference for HVE 2027.
- The original page-number index (Appendix X) is replaced by a
  topic-to-chapter table with links, and a second table of HVE 2027 topics.
