# Text Editor Dialog Box

HVE's Text Object Tool, in the 3-D Editor, creates and edits 3-D text used to label signs, buildings and other objects: its position, orientation, text and height.

!!! warning "Not in HVE 2027"
    HVE 2027 has no 3-D Editor and no 3-D text objects (see [3-D Editor Menu](3dEditor.md)). Labels that HVE 2027 draws in the Viewport are generated by the program — for example a saved camera's name (**Show Name** in the Cameras window) and the **North Arrow** (**View › Scene Display › North Arrow**). Notes about an event are kept as text in **Event › Notes** in the Event Editor.
