# User Interface

Dialog and feature reference for the **User Interface** of HVE 2027, page by page against HVE's own User Interface help. HVE 2027 replaces HVE's Windows interface with docked panels: the editor tabs **Human (F2)**, **Vehicle (F3)**, **Environment (F4)** and **Event (F5)** under the menu bar, a **Viewport** with a playback bar, and the **File**, **Edit**, **View**, **Tools** and **Help** menus plus the menus of the current editor (**Vehicle**; **Environment**; **Event** and **Output**; **Occupant**). Where an HVE dialog has no HVE 2027 equivalent, its page says so and says where the function is instead. Part of the [HVE Manual](../README.md).
