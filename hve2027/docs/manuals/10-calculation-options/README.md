# Calculation Options

Dialog reference for each calculation method's **calculation options**. Part of
the [HVE Manual](../README.md).

## Opening the options

In HVE 2027 the options of the active event are opened from the
[Event Information](../09-events-driver-controls/EventInfo.md) panel: under
**Calculation Method**, press **Method Options...**. A floating window titled
*method* **Options** (for example *EDCRASH Options*) opens. It closes by itself
if the active event changes to a different method.

- Changes take effect immediately; there is no OK or Cancel. EDCRASH's window
  has an **Apply Defaults** button.
- The options are locked while the event's results are on screen; **Reset** the
  run to edit them.
- EDSMAC and EDSMAC4 share one window, **EDSMAC Options**.
- EDSVS, EDVDS and EDVTS have no options window; their pages say why.
- Where HVE 2027 shows an option that an engine refuses, the option is offered
  (an imported HVE case may carry it) but marked, and the page says what
  happens when the event is run.
