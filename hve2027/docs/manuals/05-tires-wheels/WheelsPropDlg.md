# Wheel Properties Dialog

In HVE, clicking a wheel of the current vehicle displays a popup from which the
wheel's suspension, brake, tire, location, images and mark colors are reached.

!!! warning "Not in HVE 2027"
    HVE 2027 has no per-wheel popup. The per-wheel dialogs are on the
    **Vehicle** menu of the Vehicle editor (F3):

    | HVE popup item | HVE 2027 |
    |---|---|
    | Suspension... | **Vehicle › Suspension Data...** |
    | Brake... | **Vehicle › Brake Assembly...** |
    | Tire... | **Vehicle › Tire Data (Detailed)...**, including its **Load & Speed Tables** panel — see [Tire Information](TireInfoDlg.md) |
    | Wheel Location... | **Wheel Positions (from CG)** in the Vehicle editor's **Vehicles** panel: X, Y and Z below the CG for each wheel. A field left at 0 is derived from the vehicle's dimensions; a value typed there overrides it for that wheel. |
    | Wheel Image... | The Vehicles panel's **3D Geometry › Wheel Images**: per wheel, **Pick...** (thumbnails from the vehicle databases and WheelTextures folders, with **Use on this wheel** or **Use on every wheel**), **Browse...**, **All** and **Clear**. Display only — see [Wheel Image](../hve-users/04-vehicle-editor/11d-brakes-tires-wheels.md#wheel-image) |
    | Tire Sidewall Image..., Tire Tread Image... | Not available. |
    | Track Color..., Skid Color... | Not available per wheel. Tire marks are switched on with **View › Scene Display › Skidmarks**. |
