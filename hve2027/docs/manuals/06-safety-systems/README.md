# Safety Systems

Dialog reference for the **Safety Systems** area: one page per HVE dialog, each describing the HVE 2027 window that replaces it. Accelerometers and the airbag and belt restraint systems are on the **Vehicle** menu of the Vehicle editor (F3) and the **Event** menu of the Event editor (F5); an airbag's own properties are on the occupant, in the Human editor (F2). Part of the [HVE Manual](../README.md).
